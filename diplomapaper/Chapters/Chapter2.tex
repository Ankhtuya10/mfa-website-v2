\section{Платформын танилцуулга}
Anoce/MFA платформ нь Монголын загварын нийтлэл, дизайнер, коллекц, лүүк зураг, материал, улирал, архивын мэдээллийг нэгтгэн харуулах fashion magazine болон дижитал архивын шинжтэй веб систем юм. Платформын зорилго нь уншигчид Монголын загварын контентыг нэг дороос үзэх, хайх, ангилах боломж олгох; редактор болон админ хэрэглэгчид нийтлэл, зураг, дизайнер, коллекцийн мэдээллийг төвлөрсөн байдлаар удирдах орчин бүрдүүлэхэд оршино.

Платформ нь дараах үндсэн хэрэглэгчдэд зориулагдана.
\begin{itemize}
  \item \textbf{Зочин хэрэглэгч:} нийтлэл унших, archive үзэх, дизайнер болон коллекцийн мэдээлэл харах, хайлт хийх;
  \item \textbf{Бүртгэлтэй хэрэглэгч:} зочин хэрэглэгчийн боломж дээр нэмээд контент хадгалах, profile хэсгээ удирдах;
  \item \textbf{Админ/редактор:} нийтлэл, дизайнер, коллекц, зурагт медиа файл удирдах, нийтлэх workflow хянах, хэрэглэгчийн эрх зохицуулах.
\end{itemize}

Энэ платформ нь энгийн blog эсвэл news site-аас ялгаатай. Энгийн blog ихэвчлэн огноо болон нийтлэлийн урсгалд төвлөрдөг бол fashion magazine platform нь зурагт өгүүлэмж, дизайнерын identity, коллекцийн холбоо, лүүк зураг, материал, улирал, archive navigation, сэтгүүлийн editorial tone-д илүү ач холбогдол өгнө. Иймээс Anoce/MFA платформын үндсэн хэсэг нь public home, editorial, archive, designers, collection detail, article detail, search overlay, profile, admin CMS, media library, AI chatbot гэсэн бүрэлдэхүүнтэй байна.

\section{Одоогийн нөхцөл байдлын шинжилгээ}
Монголын загварын мэдээлэл өнөөдөр сошиал медиа пост, брэндийн веб хуудас, цахим худалдааны бүтээгдэхүүний хуудас, эвентийн зар, хувь хүний портфолио, богино нийтлэл зэрэг олон эх сурвалжид тархсан байна. Нэг дизайнерын коллекц, тухайн коллекцийн лүүк зураг, материал, улирал, холбоотой нийтлэл, дизайнерын намтар, брэндийн түүхийг нэг дороос харах боломж хязгаарлагдмал. Энэ нь уншигчид мэдээлэл хайхад төвөгтэй, редакторт контент зохион байгуулахад хүндрэлтэй, судлаачид архивын өгөгдөл цуглуулахад цаг их шаарддаг.

Загварын сэтгүүлийн платформд дараах асуудлууд илүү тод илэрч байна.
\begin{itemize}
  \item Загварын нийтлэл, зураг, collection, дизайнерын мэдээлэл олон эх сурвалжид салангид байгаа;
  \item Монгол хэрэглэгчдэд зориулсан редакцийн нийтлэл ба архивын шинжтэй нэгдсэн платформ хомс;
  \item Нийтлэл, зураг, чиг хандлага, зөвлөгөө, коллекцийн мета өгөгдлийг нэг дор хайх боломж сул;
  \item Контент нэмэх, засах, нийтлэх ажиллагаа фронтэнд кодоос хамаарахгүй байх CMS шаардлагатай;
  \item Зурагт контент олон тул медиа файл, дэлгэцийн хэмжээнд зохицох layout, хайлт/шүүлтүүр, хэрэглэгчийн хадгалалт зэрэг боломж хэрэгтэй;
  \item AI туслах ашиглах бол архивын бодит өгөгдөлд тулгуурлах контекст болон fallback хариулт шаардлагатай.
\end{itemize}

Иймээс хөгжүүлэх платформ нь нийтлэл харуулах энгийн сайт бус, уншигчийн public experience болон редакцийн admin CMS-ийг нэгтгэсэн мэдээллийн платформ байх шаардлагатай.

\section{Бизнес процессын шинжилгээ}
Платформын үндсэн бизнес процесс нь контент бэлтгэх, удирдах, нийтлэх, хэрэглэгчид хүргэх, хэрэглэгчийн хайлт/хадгалалт/AI лавлагаагаар дахин ашиглах гэсэн дараалалтай.

\begin{enumerate}
  \item Редактор загварын нийтлэл, collection story, дизайнерын мэдээлэл, зурагт материалыг бэлтгэнэ.
  \item Редактор эсвэл админ нийтлэл, дизайнер, коллекц, медиа файлыг admin CMS-д оруулна.
  \item Контент нь ангилал, таг, дизайнер, коллекц, лүүк, материал, улирал зэрэг мета өгөгдөлтэй холбогдоно.
  \item Админ нийтлэлийг хянаж батлах, засвар хүсэх эсвэл published төлөвт оруулна.
  \item Уншигч homepage, editorial, archive, designers, search overlay-оор контентыг олж уншина.
  \item Нэвтэрсэн хэрэглэгч bookmark/follow ашиглан сонирхсон контентоо хадгална.
  \item AI туслах live content болон RAG context ашиглан хэрэглэгчийн асуултад архивт тулгуурласан хариулт өгнө.
\end{enumerate}
